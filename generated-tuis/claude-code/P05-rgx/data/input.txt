test for F2 and for the (?i) inline flag. Note also that xxERRORxx below hides
a match in the middle of a token: xxERRORxx and preERRORpost.

Things to try
-------------
1[3-9]\d{9}                 mainland China mobile numbers
(?i)error                   every spelling of error, any case
(\w+)@([\w.]+)              email split into user and host, then $2 / $1
^\d{4}-\d{2}-\d{2}          a date at the start of a line, with F3 for (?m)
\b(\w+)\s+\1\b              a doubled word, via the backtracking engine
[ \t]+$                     trailing whitespace, with F3 for (?m)
